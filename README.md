# NCP-AIN Study Hub

A static GitHub Pages site for studying for the **NVIDIA-Certified Professional: AI Networking (NCP-AIN)** exam. There's one page per exam blueprint topic. Each page lists the topic's exam objectives and the recommended training and readings from NVIDIA's official exam study guide.

Only links that resolved to a live page when last checked (October 8, 2026) are included.

## Publishing

Plain HTML/CSS with no build step. In the repo, go to **Settings → Pages**, choose **Deploy from a branch**, then select `main` / `(root)`.

Not affiliated with or endorsed by NVIDIA.
