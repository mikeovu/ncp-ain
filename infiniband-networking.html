NVIDIA InfiniBand Networking

Set up and maintain InfiniBand switches, configure reliable multi-tenant networks, manage subnet managers and fabric partitioning, monitor performance with tools like NVIDIA Unified Fabric Manager (UFM), resolve congestion or topology issues, and validate advanced, rail-optimized AI data center designs for scalability and low latency.

Exam objectives

  1. 3.1Perform initial configuration and provisioning, including high availability (HA).
  2. 3.2Configure partition keys (PKeys) to ensure secure multi-tenancy in InfiniBand networks.
  3. 3.3Configure QoS and adaptive routing to dynamically adjust paths based on congestion.
  4. 3.4Use UFM to monitor InfiniBand link status and bandwidth utilization.
