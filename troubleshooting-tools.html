Troubleshooting Tools

Use diagnostic command-line tools and telemetry (e.g., cl-resource-query, WJH, ib_write_lat, NetQ, UFM) for root-cause analysis of latency, congestion, or connectivity issues in AI networks. Quickly identify faults in complex environments and recommend effective, production-ready remediation strategies.

Exam objectives

  1. 5.1Use tools like cl-resource-query to check resource allocation in Spectrum-X environments.
  2. 5.2Use WJH services for real-time event analysis.
  3. 5.3Verify low-latency interconnects between GPUs, CPUs, and storage systems.
  4. 5.4Use UFM system health to diagnose InfiniBand issues.
  5. 5.5Use commands like ib_write_lat, ib_write_bw, ibping, ibstat, ibdiagnet, ibnodes, and iblinkinfo to diagnose connectivity issues.
